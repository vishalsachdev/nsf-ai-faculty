Using AI to Learn AI

A prototype approach for the NSF Faculty AI Professional Development Program — where the medium is the message.

Faculty don't just learn about AI. They learn through AI — by directing an agent, watching it work, and stress-testing the results.

The Scenario

Walkthrough Example

A Librarian Discovers What AI Actually Sees

David is a reference librarian. He's heard faculty claim that "AI can search all the literature." He wants to understand what's actually happening under the hood.

  1. Ask the agent: "Build me a small Python script that shows exactly what data a PubMed API query returns for a search on 'CRISPR gene therapy.' Show me the raw fields."
  2. Watch it work: The AI agent (Codex) creates the script in a sandbox, runs it, and displays the results — titles, abstracts, MeSH terms, author lists. No full text.
  3. Probe: "Wait — where's the full text of the articles?" The agent explains: PubMed indexes metadata. Full text lives behind publisher paywalls. AI tools trained on PubMed see titles and abstracts, not the papers themselves.
  4. Stress-test: "So if a student says 'AI reviewed 500 papers on my topic,' what did it actually review?" The agent generates a concrete comparison: what a human reads vs. what the AI actually accessed.
  5. Reflect: David now understands a fundamental limitation he can teach to every student who walks into the library.
The learning moment

David didn't read a slide about AI limitations. He discovered the limitation himself by directing an AI agent and interrogating its output. The understanding is durable because he built it.

How It Works

Faculty interact with an AI coding agent (like OpenAI Codex) inside a sandboxed environment. They don't need to know how to code — they describe what they want to see, and the agent builds it live.

Each module provides guided prompts tailored to the faculty member's discipline, designed to surface key insights about how AI works through direct experimentation — not lectures.
